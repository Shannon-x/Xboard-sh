# 权限组节点与套餐明细

管理员的 `GET server/group/fetch?include_details=1` 在原列表字段外返回：

- `nodes`：该组全部节点的 `id/name/type/show/rate`，包含隐藏节点，不返回连接地址、端口、协议配置、证书或密钥。
- `visible_server_count`：在订阅中显示的节点数。
- `plans`：引用该组的套餐，`mode` 区分 `base`、`included`、`optional`；增值组附带用户展示名 `label` 和按分计的月费 `price`。
- `pricing_plan_count`：仅历史流量计价引用的套餐数。这些引用不授予权限，也不会出现在 `plans` 中。

未指定 `include_details` 的旧调用保留精简响应。明细读取执行固定三次数据库查询，不按组逐个查询节点。接口沿用已有管理员鉴权和路由，不需要增加中间件路由。

组名修改后立即清理增值组名称缓存，不修改套餐展示名、价格、节点分组或用户授权。删除时检查节点、基础套餐/用户、套餐增值配置、历史计价、已购增值组和管理员授权，存在引用则拒绝删除。

配套 XBoard-admin 提供权限组搜索、关联方式筛选、节点与套餐明细、显示/隐藏节点筛选，以及套餐编辑中的节点预览。通过 `group_id` 精确定位权限组，通过 `group_id` / `node_id` 定位节点管理；查看明细不保存表单或改变权限。

验证：`ServerGroupManagementTest` 覆盖鉴权、字段白名单、节点范围、计价与授权区分、固定查询次数、改名缓存与不改权益、删除引用保护和名称校验。另运行全量 Unit/Feature 回归以及内置管理端构建和模拟接口浏览器检查。
